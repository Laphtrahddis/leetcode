# [412. Fizz Buzz](https://leetcode.com/problems/fizz-buzz/)

**Difficulty:** Easy · **Topic:** Strings · **Solved:** 2026-11-07 · **Language:** Python3

**Approach:** loop from 1 to n; check "divisible by both 3 and 5" first, then 3, then 5, otherwise use the number itself as a string.

**Complexity:** O(n) time, O(n) space for the output list.
